# 당황Zero MVP Scope

## 한 줄 목표

사고 직후 사용자가 사고 유형을 직접 판단하지 않아도, 앱이 쉬운 단계형 질문과 사진 안내를 통해 상황 후보를 유추하고 필요한 초기 대응 기록을 빠뜨리지 않게 돕는다.

## Primary User

교통사고 직후 당황해서 어떤 정보를 기록해야 할지 모르는 운전자

## 사용자 Pain Point

- 사고 직후에는 다친 사람 확인, 사진 촬영, 차량 이동, 보험사 연락 순서를 판단하기 어렵다.
- 파손 부위만 찍고 전체 현장, 번호판, 위치, 표지판 같은 증거를 빠뜨릴 수 있다.
- 일반 AI 챗봇은 사용자가 상황을 길게 설명해야 해서 사고 직후 사용하기 어렵다.

## MVP 핵심 가치

사용자가 사고 유형을 먼저 고르지 않아도, 앱이 짧은 질문과 버튼형 UI로 사고 상황을 파악하고 필요한 기록과 행동을 단계별로 안내한다.

## Must Have

1. 사전 정보 등록
   - 차량번호, 차종, 보험사, 긴급 연락처를 저장한다.

2. 사고 대응 시작
   - 사고 발생 시 위치와 시간을 저장하고, 사전 등록 정보를 불러온다.
   - 첫 단계에서 부상 여부와 현장 위험 여부를 확인한다.

3. 단계형 상황 파악
   - 다친 사람 여부, 차량 이동 가능 여부, 상대 차량 여부, 시설물 파손 여부를 버튼/칩/카드 UI로 입력받는다.

4. 사진 기록 안내
   - 전체 현장, 파손 부위, 번호판, 표지판/신호등, 시설물 사진 항목을 한 번에 하나씩 안내하고 누락 여부를 확인한다.

5. 체크리스트와 사고 요약
   - 상황 후보와 누락 항목에 맞는 다음 행동, 체크리스트, 사고 기록 요약을 생성한다.

## Should Have

1. 누락 정보 재질문
2. 사진 업로드 실패 재시도
3. 위치 권한 거부 시 수동 입력
4. 데모 데이터 초기화
5. OpenCV 기반 사진 품질 검사
6. 10초 무응답 시 음성 읽기 또는 화면 강조

## Could Have

1. LLM 기반 사고 요약 보조
2. Google Cloud Vision 기반 PhotoFacts 생성
3. Gemini 기반 PhotoFacts 보완
4. YOLO pretrained 객체 탐지
5. 사고 기록 PDF 내보내기

## Won't Have for MVP

1. 과실비율 판단
2. 법적 책임 판단
3. 보험금 판단
4. 보험사 실시간 접수 연동
5. 경찰/소방 시스템 연동
6. 파손 부위 학습 모델
7. 번호판 OCR 확정 저장
8. AI가 단독으로 사고 유형, 책임, 신고 필요성을 확정하는 기능

## 데모 성공 기준

- 핵심 데모 시나리오가 동일 환경에서 3회 연속 성공한다.
- 사고 대응 시작부터 체크리스트 확인까지 3분 이내 완료한다.
- 데모 데이터에 실제 개인정보가 0개다.
- AI/CV 기능이 꺼져도 기본 흐름이 동작한다.
- 앱은 과실, 법적 책임, 보험금 판단을 하지 않는다.
- mock PhotoFacts 또는 녹화 응답으로 네트워크 없이도 핵심 시나리오를 설명할 수 있다.
