# 당황Zero Feature List

## Must Have 기능

| ID | 기능 | 담당 | 설명 | 완료 기준 |
| --- | --- | --- | --- | --- |
| F-01 | 사전 정보 등록 | 프론트, 백엔드 | 차량번호, 차종, 보험사, 긴급 연락처를 저장한다. | 등록 후 사고 대응 시작 시 정보가 자동 표시된다. |
| F-02 | 사고 대응 시작 | 프론트, 백엔드 | 위치, 시간, 등록 정보를 기반으로 사고 기록을 생성한다. | `accident_id`가 생성되고 다음 화면으로 이동한다. |
| F-03 | 안전 확인/단계형 상황 파악 | 프론트, AI | 부상/위험 확인을 먼저 하고, 사고 유형 직접 선택 대신 버튼형 질문으로 상황 정보를 수집한다. | 긴급 후보 또는 상황 후보가 단정 표현 없이 표시된다. |
| F-04 | 사진 기록 안내 | 프론트, 백엔드, CV | 필수 사진 항목을 한 번에 하나씩 안내하고 업로드 상태와 누락 상태를 관리한다. | 다음에 찍을 사진 또는 누락 항목이 표시된다. |
| F-05 | 다음 행동/체크리스트/요약 | AI, 백엔드, 프론트 | 상황 후보와 누락 상태를 바탕으로 NextAction, 체크리스트, 요약을 제공한다. | 결과 화면에서 다음 행동, 체크리스트, 요약이 표시된다. |

## Should Have 기능

| ID | 기능 | 담당 | 설명 | 완료 기준 |
| --- | --- | --- | --- | --- |
| S-01 | 위치 수동 입력 | 프론트, 백엔드 | 위치 권한 거부 시 주소/메모를 입력한다. | 권한 거부 후에도 사고 기록 생성 가능 |
| S-02 | 업로드 재시도 | 프론트 | 사진 업로드 실패 시 재시도한다. | 실패 메시지와 재시도 버튼 표시 |
| S-03 | 누락 정보 재질문 | AI, 프론트 | 상황 유추에 필요한 답변이 부족하면 추가 질문을 표시한다. | 동점 후보 발생 시 추가 질문 표시 |
| S-04 | 데모 데이터 초기화 | 백엔드 | 평가용 더미 데이터를 초기화한다. | 실제 개인정보 없이 데모 상태 복구 |
| S-05 | 무응답 보조 안내 | 프론트 | 사용자가 10초 동안 응답하지 않으면 같은 안내를 음성 또는 화면 강조로 다시 보여준다. | 전화는 자동 실행하지 않고 사용자가 직접 누를 때만 동작 |

## 개발/검증 지원 기능

이 기능들은 사용자가 직접 쓰는 핵심 기능은 아니지만, 구현과 시연 안정성을 위해 준비한다.

| ID | 기능 | 담당 | 설명 | 완료 기준 |
| --- | --- | --- | --- | --- |
| D-01 | PhotoFacts 계약 | AI, CV, 백엔드 | 사진 분석 결과를 고정 JSON 형식으로 교환한다. | mock PhotoFacts만으로 분류/누락 분석 가능 |
| D-02 | NextAction 계약 | AI, 백엔드, 프론트 | 앱이 다음에 보여줄 행동을 고정 JSON 형식으로 전달한다. | 프론트가 action kind별 화면을 그릴 수 있음 |
| D-03 | 시나리오 실행기 | 백엔드, AI | YAML 시나리오로 mock 답변, mock 사진 관찰, 무응답을 주입한다. | 핵심 시나리오 12개 자동 검증 |
| D-04 | 녹화 응답 재생 | CV, 백엔드 | 실제 비전 API 응답을 저장하고 같은 입력에서 재생한다. | 네트워크 없이 재생 모드 동작 |
