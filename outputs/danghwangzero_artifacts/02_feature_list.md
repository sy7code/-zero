# 당황Zero Feature List

## Must Have 기능

| ID | 기능 | 담당 | 설명 | 완료 기준 |
| --- | --- | --- | --- | --- |
| F-01 | 사고 대응 시작 | 프론트 | 시작 버튼으로 시각과 위치를 기록하고 로컬 사고 기록을 생성한다. | Hive에 `accident_id`와 시각/위치 출처가 저장된다. |
| F-02 | 안전 확인 | 프론트, 규칙 | 부상, 연기/화재, 2차 사고 위험을 먼저 확인한다. | 긴급 후보일 때 긴급 화면으로 분기하고 자동 전화는 하지 않는다. |
| F-03 | 쉬운 질문 | 프론트, 규칙 | 버튼 2-4개와 `모름`으로 상황 정보를 수집한다. | 사용자가 텍스트를 쓰지 않아도 상황 후보가 표시된다. |
| F-04 | 사진 기록 안내 | 프론트, CV 후보 | 필요한 사진을 한 번에 하나씩 요청하고 누락 항목을 관리한다. | 전경, 번호판, 파손, 시설물 등 slot 상태가 저장된다. |
| F-05 | 사고 기록 카드 | 프론트 | 기록된 정보를 카드와 히스토리로 보여준다. | 홈에서 이전 사고 기록을 다시 열 수 있다. |

## Should Have 기능

| ID | 기능 | 담당 | 설명 | 완료 기준 |
| --- | --- | --- | --- | --- |
| S-01 | 위치 수동 입력 | 프론트 | 위치 권한 거부 시 주소/메모를 입력한다. | 권한 거부 후에도 사고 기록 생성 가능 |
| S-02 | 무응답 보조 | 프론트 | 10초 동안 응답이 없으면 음성 읽기 또는 화면 강조를 실행한다. | 자동 신고 없이 같은 안내를 재제시 |
| S-03 | 사진 품질 검사 | CV/백엔드 | 흔들림, 밝기, 크기를 확인한다. | 품질 실패 시 비전 API 호출 없이 재촬영 요청 |
| S-04 | replay 모드 | 백엔드, AI/CV | 저장된 비전 응답을 재생한다. | 네트워크 없이 같은 PhotoFacts 반환 |
| S-05 | 데모 데이터 초기화 | 프론트 | 평가용 더미 데이터를 초기화한다. | 실제 개인정보 없이 데모 상태 복구 |
