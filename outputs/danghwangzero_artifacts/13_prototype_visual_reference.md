# 당황Zero Prototype Visual Reference

이 문서는 `3조3차.pdf`의 데모 화면 방향을 Flutter 프로토타입에 반영하기 위한 기준이다.

## 기준

최신 화면 방향은 3차 자료의 7개 데모 화면을 따른다.

1. 홈
   - 버튼 하나로 시작한다.
   - 첫 화면에서 `버튼만 누르는 대응`, `사진은 관찰 기록으로`, `기록은 내 폰에만`을 바로 보여준다.

2. 안전 확인
   - 질문 하나만 보여준다.
   - 버튼은 `있음`, `없음`, `모름` 세 가지로 제한한다.
   - `있음` 또는 `모름`이면 긴급 화면으로 이동한다.

3. 촬영 안내
   - 화면 중앙에 촬영 가이드 틀을 둔다.
   - 요청 이유를 한 줄로 보여준다.
   - 사진은 판단 근거가 아니라 관찰 기록으로 취급한다.

4. 쉬운 질문
   - 사용자가 문장 입력을 하지 않는다.
   - AI 후보가 있어도 사용자가 버튼으로 확인한다.

5. 긴급 화면
   - 빨강은 긴급 전용으로만 쓴다.
   - 전화는 자동 실행하지 않고 사용자가 직접 누른다.
   - 정식 배포 전에는 실제 112/119가 아니라 데모 번호로 연결한다.
   - 신고 후에도 기록을 계속할 수 있다.

6. 사고 기록 카드
   - 보험 처리에 필요한 항목을 한 화면에 모은다.
   - 상황 후보, 누락 사진, 건너뛴 사진, 진행 로그를 보여준다.
   - 과실, 법적 책임, 신고 필요 여부는 확정하지 않는다.

7. 히스토리
   - 최근 사고 기록을 홈에서 다시 볼 수 있다.
   - 기록은 사용자 기기 로컬 저장소에 남는다.

## Flutter Prototype 반영 상태

- `app/lib/main.dart`에 홈, 안전 확인, 쉬운 질문, 촬영 안내, 긴급 화면, 사고 기록 카드 흐름을 반영했다.
- 실제 3차 이미지 파일을 앱 asset으로 넣지는 않았다.
- 현재 화면은 발표용 최종 UI가 아니라 데모 흐름 확인용 프로토타입이다.
